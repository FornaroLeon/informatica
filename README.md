Progetto che simula il gioco CrazyTime, una ruota della fortuna che gira e fa uscire dei risultati casuali come numeri o caselle speciali. 
Hai un certo numero di soldi che ti puoi giocare e in base alla cifra che esce la quantità che hai giocato si moltiplica.   
Inoltre ogni spin viene caricato e salvato nel file .csv.
